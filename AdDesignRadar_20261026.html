01. Figma · 从创意工具走向可治理的生产系统

访问官方来源 ↗
事实与时间边界

Figma 官方 Release Notes 显示，10 月 22 日 Enterprise 管理员可设置付费 AI credits 默认权限、通过 SCIM 管理 AI credits 访问与额度、阻止员工使用公司邮箱创建外部 Starter 或 Professional 计划，并使用新的管理员 REST API 管理团队、文件夹和文件；官方标注这些能力将在接下来几天陆续推送。10 月 23 日新增 iPhone Duo 与 iPhone 18 frame presets，覆盖创建 frame、code layer、prototype settings、Make preview 和 code layers 全屏视图。它们是管理与设计预设更新，不等于 AI 自动完成广告。

行业洞察与广告价值

广告团队经常同时面对两个问题：一是生成式功能让额度和外部账号变得难以追踪，二是同一产品要适配越来越多设备、版位和原型演示。上周的 Figma 更新把“谁能用 AI、额度如何分配、哪里能创建外部空间”纳入治理，并把设备预设前置到设计和原型阶段。对跨团队代理而言，这比再增加一个视觉滤镜更接近真实成本和交接瓶颈。

🎯 商业实战 · TikTok / Meta

输入：已批准的品牌库、真实产品截图、真实 App 录屏、英文与本地化文案、目标设备和版位清单。先用 iPhone 18 等预设制作产品演示原型，再分别输出 TikTok 9:16 的首屏路径与 Meta 4:5 的静音理解版本。Enterprise 管理员为探索项目和正式项目设置不同 AI credits 权限，避免代理在共享空间里无限试错。产品结果、价格、评价和 CTA 仍由真实图层或真实录屏承载；frame preset 只能保证画布起点，不能证明产品在目标设备上真实运行。

⚖️ 优势、限制、成本与合规

优势：把 AI 使用权限、组织管理、版位预设和原型流程放在同一生产链，适合多客户、多设计师和有设计系统的团队。限制：部分 Enterprise 管理功能在逐步推出；AI credits、SCIM、管理员 API、客户文件可见性和外部 MCP 数据流需要核对。预设名称更新也可能影响旧模板与自动化脚本，不能只看画布是否能打开。

建议与验收：先选一个 App 广告项目，做 2 个版位 × 2 种语言 × 2 个 hook 的小样；记录权限误配、旧组件调用、设备预设错误、人工修改时长和 credits。若任何人仍能绕过项目预算或原型持续调用不存在的功能，应先修治理，不扩大 AI 使用量。

来源：Figma Release Notes，10/22 与 10/23 条目；查阅日期：2026-10-26。

上周平台接入更新 · 10/14、10/15MCP / 音效 / 去背 / 配音

02. Runway MCP · 把中间资产处理接进代理工作流

访问更新日志 ↗
事实与时间边界

Runway 官方 Changelog 记录：10 月 14 日 Fish Audio Drama 3 进入 Runway MCP，可按脚本和 delivery cues 生成七种声音及表达；10 月 15 日 Mirelo SFX 2.0 进入 MCP，可从片段和描述生成独立音轨；同日 BiRefNet v2 Background Removal 进入 MCP，可自动检测前景，为产品图、插画和合成准备去背。这些是平台接入更新，不等同于模型首发，也不代表所有账号和计划都有相同权限。

行业洞察与广告价值

这组更新的共同点是把广告制作中经常被单独处理的“声音、音效、前景分离”变成可调用的中间步骤。对于 TikTok 和 Reels 风格素材，制作瓶颈往往不是没有主画面，而是产品抠图不干净、音效没有节奏、口播和画面版本无法对应。MCP 能减少工具切换，但代理越能自动串联步骤，越需要把真实产品、批准脚本和最终音频分开管理。

🎯 商业实战 · TikTok / Meta

以 15 秒 App 或电商广告为例：先输入真实产品图或真实录屏帧，用 BiRefNet v2 准备透明前景；再用已批准的英文脚本生成两种 Drama 3 口播表达；最后用 Mirelo SFX 生成轻量点击、滑动或转场音效。TikTok 9:16 版本让音效服务于前三秒动作和字幕节奏；Meta 4:5 版本保留静音可理解性，声音只作为增强层。包装文字、App UI、价格、功效和人物证言不能由这些中间工具补造。

⚖️ 优势、限制、成本与合规

优势：独立音轨和透明前景便于在 PR / AE 中重新编排，适合一个母版派生多个版位。限制：去背可能误伤透明包装、头发和细小边缘；生成音效可能与品牌声学风格冲突；Drama 3 的七种声音和 delivery cues 不等于自然口播或人物授权。MCP 连接权限、第三方模型数据处理、积分消耗和音频商用权利必须分别核对；本期未实测。

建议与验收：先拿一个不承载敏感功效的产品镜头做 6 个小样：2 种去背、2 种口播、2 种音效。验收边缘、品牌名读法、字幕同步、静音可懂度和总成本；只要真实产品边缘或脚本事实出错，就停止自动串联，回到人工处理。

来源：Runway Changelog，10/14 与 10/15 条目；查阅日期：2026-10-26。

03. CapCut · 教程密集更新，适合把概念接到粗剪

访问官方资源页 ↗
事实与时间边界

CapCut 官方资源页显示，10 月 21 日集中发布 Mac 下载、AI 图片生成、4K 视频增强、文本生成视频、AI Avatar 等教程；10 月 23 日发布“在线去除视频对象”的方法文章，介绍在线 Mask 与桌面 AI Remove 等工作方式。这些是官方内容与教程更新，不能据此推断上周发布了新的核心模型、商用授权或稳定性能。

行业洞察与广告价值

CapCut 的实际价值更接近低门槛的概念筛选、社交剪辑和快速版本适配。对于设计师，教程更新有助于发现“先去除干扰、再增强画面”的制作路径，但它不能替代 PR / AE 的精确合成，也不能替代对产品事实和版权的核验。内容更新密集，反而提醒团队要把教程建议与真实项目验收分开。

🎯 商业实战 · TikTok / Meta

输入一段已授权 UGC、真实产品参考、三种 campaign proposition 和目标字幕。先复制一条短片做概念粗剪：去除画面中无关物体，只改变背景干扰，不改变人物动作和产品事实；再输出 TikTok 9:16 的 3 秒钩子版本与 Meta 4:5 的产品主体版本。AI 图片或文本生成视频只用于背景和气氛候选，最终产品包装、价格、折扣、UI 和 CTA 用真实素材覆盖。

⚖️ 优势、限制、成本与合规

优势：入口清楚、适合快速迭代，能把去物、字幕、增强和基础版位适配放在同一条低门槛路径。限制：去物可能留下纹理或遮挡痕迹，4K 增强不会恢复真实细节，AI Avatar 与模板内容可能产生不自然的表情或版权问题。模板、音乐、字体、人物素材的商业使用条件不能只看页面上的“免费”标签；地区与设备权限也可能不同。

建议与验收：每个方向只做 3 个版本，用产品准确度、字幕可读性、去物痕迹、版位适配、后期可继续编辑性和授权风险评分。若概念粗剪不能帮助团队更快排除方向，就停止增加生成量，回到 brief 和真实资产。

来源：CapCut 官方资源页，10/21 与 10/23 条目；查阅日期：2026-10-26。内容更新不等于产品首发。

04. Descript · 真实素材协作与声音版本更可追踪

查看官方更新 ↗
事实与时间边界

Descript 的 Release roundup—October 12, 2026 页面于 10 月 13 日公开。更新包括全盘文件搜索、Enterprise 异步录制请求、AI Speech 接入 ElevenLabs v4、付费计划视频默认使用 MiniMax H3 Max Turbo、AI credits 与媒体分钟数支持最长 12 个月使用历史、Search API 与 MCP 返回项目和文件直链，以及若干发布和导出修复。页面是产品更新汇总，不代表所有计划或地区都可用。

行业洞察与广告价值

在 AI 生成变多之后，真实 UGC 的获取、整理和版本追踪仍然是广告团队的硬问题。异步录制请求能减少安排通话的摩擦；全盘搜索和直链有助于把“最终口播”“最终最终版”变成可找的资产；ElevenLabs v4 则能用于在不重拍的前提下做有限的声音修订。但它们都不能证明合成人物是真实用户，也不能自动保证改后的语气符合品牌或授权范围。

🎯 商业实战 · TikTok / Meta

先发一份带脚本、拍摄要求和截止时间的异步录制请求，获取真实使用者的 30—60 秒回答；在 Descript 中校正转写、搜索关键句并整理为 15—25 秒版本。只有在原始录音授权允许且必须修正轻微读错时，才评估 AI Speech；不把声音替换成新的“客户证言”。TikTok 保留自然停顿和手持感；Meta 版本补充产品近景与可静音理解字幕。发布前核对原始文件、脚本版本、声音授权和落地页事实。

⚖️ 优势、限制、成本与合规

优势：真实录制、文本剪辑、搜索和版本链接适合多人审片；异步录制能减少跨时区协作；使用历史有助于追踪 AI credits 和媒体分钟数。限制：AI voice clone 仍需明确授权，口音和情绪可能改变；自动修复、重生成和 MiniMax 默认模型会影响成本和一致性。Enterprise、付费计划、模型切换和 API / MCP 权限需核对，不能把更新汇总当作统一可用性。

建议与验收：用 3 条真实授权口播做小样，比较人工剪辑、AI Speech 修订和原声版本的人味、事实完整性、口型 / 音画、审片时间和成本。若合成版本改变证言含义或无法保留授权记录，停止使用 AI 修订。

来源：Descript Release roundup—October 12, 2026，公开日期：2026-10-13；查阅日期：2026-10-26。

05. Midjourney · 仍适合作为概念探索，不是上周新功能

查看官方更新 ↗
事实与时间边界

Midjourney 官方更新页在本次查阅时显示的最近公告为 10 月 8 日 Testing Thinking Mode 与 Alpha Changelog - 10/7/26，页面没有显示 10 月 19—25 日的新公告。因此本卡只保留为近期能力补充，不写成上周更新。10 月 8 日公告描述了对物体、布局、人体结构和文字进行再生成的测试能力；测试状态不等于稳定生产能力。

行业洞察与广告价值

Thinking Mode 的广告价值仍是帮助设计师把“错误的构图方向”快速修正为可讨论的 moodboard，而不是直接产出可投放主视觉。它适合在 brief 尚未锁定时比较人物关系、背景、色调与留白；不适合承载包装文字、价格、优惠、真实用户体验或需要精确产品比例的画面。上周没有新公告本身也是信息：不能为了凑工具数量把旧能力伪装成新趋势。

🎯 商业实战 · TikTok / Meta

输入不含事实承诺的视觉 brief 和公开授权参考图，固定产品占比、人物位置和字幕留白，只比较三种构图。TikTok 9:16 检查首帧与字幕空间；Meta 4:5 检查主体裁切与静音阅读。Thinking Mode 只用于概念修正；最终 Logo、包装、UI、价格、免责声明和 CTA 必须在 Figma、PS、PR / AE 中用真实资产重建。

⚖️ 优势、限制、成本与合规

优势：适合快速得到可比较的创意方向，并把后期重建范围提前暴露。限制：测试功能可能变化，文字、手部、产品比例和版权仍需人工检查；共享或公开图片的隐私范围、Stealth 设置、团队权限和输出商用条款需要分别核对。每次重跑都可能增加成本，却不一定减少后期重建。

建议与验收：把它限定在内部 moodboard。用 10 张概念图记录可用构图数、真实资产替换量、人工重建时间和隐私风险；若 Thinking Mode 让画面更复杂但没有减少后期工作，就不迁移到正式广告主视觉。

来源：Midjourney Updates，最近可见公告10/08；查阅日期：2026-10-26。明确标注为非上周更新。

⚡ 深度实战：两条上周可执行工作流

以下是编辑设计的制作方案，不是已运行的自动化流程；没有上传客户素材、付费生成或投放实测。

1
工作流 A：Figma 治理与原型 → 真实产品演示 → PR / AE 交付输入批准的设计系统、真实 App 录屏、真实产品图、已审文案和目标版位。先在 Figma 中使用设备预设建立 9:16 与 4:5 的产品路径，只开放 hook、locale 和背景资产变量；Enterprise 管理员为探索与正式项目设置 AI credits 与外部创建边界。用真实录屏替换原型中的假数据，再到 PR / AE 重构字幕、节奏、音画和 CTA。人工审核锁定层、事实、版权、AI 使用记录、落地页和最终导出；记录错误类型、credits、修订次数和交付时间。
2
工作流 B：真实 UGC 异步录制 → Descript 文本剪辑 → Runway / CapCut 中间资产处理输入有授权的录制请求、批准脚本、真实产品镜头和平台版位规格。先在 Descript 收集并搜索真实口播，保留能独立成立的表达，不拼接未说过的效果承诺；再用 Runway MCP 准备去背、独立音效和有限口播候选，CapCut 只负责概念粗剪或社交版位适配。TikTok 重点验收前三秒、自然节奏和字幕；Meta 重点验收 4:5 主体、静音理解和落地页一致性。声音、人物、音乐和产品使用权任何一项不清楚，都停止自动生成。

🚨 避坑雷达

风险一：把治理功能当作自动合规。Figma 的 AI credits、SCIM 和外部创建控制能帮助组织管理权限与成本，但不能判断某句广告文案是否真实、某张图片是否有版权或某个素材是否符合 TikTok / Meta 政策。治理验收必须和内容审查、素材授权、品牌审批分开。

风险二：把中间资产处理当成最终成片。去背、音效和 AI Speech 可以减少剪辑摩擦，但边缘、口音、口型、情绪和字幕同步仍可能出错。用真实产品、真实录屏和真实口播做参照；一旦生成层改变事实或证言含义，回退到人工合成或原始录音。

风险三：把教程和旧公告冒充上周趋势。CapCut 的 10/21—23 页面主要是教程内容，Midjourney 本期没有 10/19—25 新公告。报告应分别记录产品更新、平台接入、文章日期、账号可用性和实际测试日，不能为了凑齐工具而扩大“上周更新”的范围。

💎 上周专属资产

资产 A：受控的广告素材处理 Prompt

适合在代理或编辑工具中整理中间资产；不允许把生成结果直接当作事实证据。

Prepare intermediate assets for [CAMPAIGN] using only these approved inputs: [REAL PRODUCT MEDIA], [APPROVED SCRIPT], [VOICE RIGHTS], and [BRAND GUIDELINES]. Create separate outputs for: transparent foreground, optional sound effect, and voice draft. Do not change product geometry, packaging text, price, UI, testimonial meaning, or CTA. Keep every generated element labeled as DRAFT until a human reviewer checks it. Return: source file, output file, model or tool, estimated cost, rights check, mismatch list, and stop/rebuild recommendation.

替换变量后先做 2—3 个小样，核对边缘、音效节奏、品牌名读法和字幕同步；不要让提示词替代人工审片或授权记录。

资产 B：TikTok / Meta 双版位验收 Prompt

Review [CREATIVE_ID] for TikTok 9:16 and Meta 4:5 against the approved source package. Check: first-frame clarity, silent comprehension, subtitle accuracy, product geometry, logo, price, claims, CTA destination, crop, audio rights, image rights, AI disclosure, and landing-page consistency. Separate VERIFIED, CONCEPT-ONLY, and NEEDS-VERIFICATION elements. For every mismatch, state severity, required real asset, owner, cost risk, and whether to stop or rebuild. Do not infer approval from visual similarity.

该模板只负责整理验收项，不提供平台政策结论；敏感品类、地区规则和最终投放资格仍需由有权限的团队确认。
